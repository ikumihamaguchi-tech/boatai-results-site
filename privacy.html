193ボートAI プライバシーポリシー

本ポリシーは、193ボートAI(以下「当方」)が運営するWebサイトおよび関連ツールにおける情報の取り扱いを定めるものです。

1. 収集する情報

当サイトは、会員登録機能・コメント機能等を持たず、訪問者の個人情報を収集しません。ホスティング事業者(Cloudflare)により、サービス提供に必要な標準的なアクセスログが処理される場合があります。

2. YouTube API サービスの利用について

当方の動画投稿ツールは、YouTube API サービスを利用して、当方自身が運営するYouTubeチャンネルへ動画をアップロードします。本ツールは当方のみが使用するものであり、第三者のYouTubeアカウント情報・視聴者情報・他者の動画データへのアクセス、取得、保存は一切行いません。

YouTube API サービスの利用にあたっては、YouTube利用規約およびGoogleプライバシーポリシーが適用されます。

3. 掲載内容について

当サイトに掲載する成績は、システムの選定通知を機械的に購入した場合の仮想成績であり、的中や利益を保証するものではありません。舟券の購入は20歳以上・ご自身の判断と責任で行ってください。
