193ボートAI プライバシーポリシー

本ポリシーは、193ボートAI(以下「当方」)が運営するWebサイトおよび関連ツールにおける情報の取り扱いを定めるものです。

1. 収集する情報

当サイトは、会員登録機能・コメント機能等を持たず、訪問者の個人情報を収集しません。ホスティング事業者(Cloudflare)により、サービス提供に必要な標準的なアクセスログが処理される場合があります。

2. YouTube API サービスの利用について

当方の動画投稿ツールは、YouTube API サービスを利用して、当方自身が運営するYouTubeチャンネルへ動画をアップロードします。本ツールは当方のみが使用するものであり、第三者のYouTubeアカウント情報・視聴者情報・他者の動画データへのアクセス、取得、保存、共有は一切行いません。

YouTube API サービスの利用にあたっては、YouTube利用規約およびGoogleプライバシーポリシーが適用されます。

3. データの保存と削除ポリシー

本ツールが保存するのは、当方自身のチャンネルへの投稿に必要な認証情報(OAuthトークン)のみで、当方の管理するサーバーに安全に保管し、第三者と共有しません。ユーザーデータ(第三者のYouTubeデータ)は収集・保存しないため、保存期間・削除対象となるユーザーデータは存在しません。

Googleアカウントへのアクセス許可は、Googleセキュリティ設定からいつでも取り消すことができます。取り消しやお問い合わせを受けた場合、当方は保有する関連認証情報を速やかに削除します。

4. 掲載内容について

当サイトに掲載する成績は、システムの選定通知を機械的に購入した場合の仮想成績であり、的中や利益を保証するものではありません。舟券の購入は20歳以上・ご自身の判断と責任で行ってください。
